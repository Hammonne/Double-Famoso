        ¿Cómo se calcula?

        Se tapa una zona con gris (usando los puntos de referencia de face_recognition), se recalcula el embedding y se mide cuánto cambia la distancia. Se tapa una foto a la vez y se promedian los dos cambios, para que el parche gris no acerque artificialmente las caras.

        ▲ sube: sin esa zona se alejan, así que la zona los hacía parecidos. ▼ baja: la zona los diferenciaba.

        Ojo: muestra qué zonas usa el modelo para decidir. Las 128 dimensiones del vector no corresponden una a una a "ojos" o "cabello": esa información está repartida en todo el vector. Técnica: occlusion sensitivity (Zeiler & Fergus, 2014).
